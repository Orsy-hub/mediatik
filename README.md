# Mediatik

Mediatik est une plateforme musicale permettant de gérer, publier et consommer du contenu musical (audio, visuels, informations artistes, playlists, etc.).  
Le projet est divisé en deux applications principales :

- **Frontend** : Next.js (interface utilisateur)
- **Backend** : Django (API / Base de données / Auth / Services)
